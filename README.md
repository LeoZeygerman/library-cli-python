📚 Library CLI Python
Консольная система управления библиотекой, написанная на Python.
Проект позволяет добавлять, искать и удалять книги, а также хранить данные в JSON-файле.
🚀 Возможности
Добавление новых книг
Поиск книги по названию
Поиск книг по автору
Удаление книг
Хранение данных в JSON
Простое консольное меню
📁 Структура проекта
library-cli-python/
│
├── main.py
├── models.py
├── storage.py
├── add_book.py
├── find.py
├── delete.py
│
└── data/
    └── books.json
⚙️ Установка и запуск
Клонируйте репозиторий:
git clone https://github.com/LeoZeygerman/library-cli-python.git
Перейдите в папку проекта:
cd library-cli-python
Запустите программу:
python main.py
